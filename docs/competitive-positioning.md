# Competitive positioning

| Entry | Primary promise | ProofPact difference |
| --- | --- | --- |
| DegenLens | Verified gambling intelligence | ProofPact consumes intelligence to settle agent labor |
| Legwork | Autonomous job applications | ProofPact verifies whether an agent completed paid work |
| Cognivern | Budget and policy before spending | ProofPact verifies the delivered outcome before settlement |
| Deycid | Buy intelligence until confidence is sufficient | ProofPact ties multi-intent verification to a contractual milestone |
| ProofRoute | Gate an onchain transaction | ProofPact turns that kernel into a vertical agent-work marketplace |
| PREFLIGHT / EviPlan | Supply safety or evidence signals | Those Miners can become verification providers consumed by ProofPact |

ProofPact’s distinction is the complete loop: **agent-work escrow → independent multi-intent verification → deterministic policy → onchain outcome settlement**.

As of 4 September 2026, we found no publicly indexed Telegraph Track 3 project presenting this exact loop. This is a bounded research claim, not a guarantee about private builds or Discord-only entries, and it must be rechecked before submission.

## Defensibility

The moat is not a generic escrow contract. It is the growing library of versioned policy packs, outcome-specific evidence normalizers, Miner-quality telemetry, auditable receipts, and integrations that translate research, data, content, growth, protocol, and agent work into claims Telegraph can verify.
